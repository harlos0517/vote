# UI 設計規格

來源：Harlos 提出的設計（2026-11-23），以及後續的確認問答。標示「待確認」的項目尚未定案。

## 1. 共通功能

| 功能 | 規格 |
|---|---|
| 計入無效票 | 選項。開啟後分母由「有效票」改為「投票數」。 |
| 計入未投票 | 選項。開啟後分母改為「選舉人數」；未投票 ＝ 選舉人數 − 投票數。 |
| 無效票、未投票的角色 | 只改變分母並出現在投票環中，**不作為選項參與「當選／最多」判定**。 |
| 顏色 | 可選連續色或分段色。 |
| 投票環 | 顯示在地圖角落，內容為目前選取（鎖定或 hover）的地區；沒有選取時顯示全國或該選舉的整體範圍。開啟計入選項時，加入「無效票」「未投票」區塊。 |
| 互動 | 滑鼠滑過時，側邊資訊與投票環跟著更新；點選後鎖定，點空白處解除。**不使用 tooltip。** 觸控裝置沒有 hover，點一下即鎖定。 |
| 選區／地區 highlight | 滑過或鎖定時，highlight 所屬的選區或地區。鄉鎮層級可能跨兩個選區（例如新竹市東區、北區），這時兩個選區都要 highlight，村里層級才精確。 |
| 年份滑桿 | 依選舉種類分開。同種類、相距 12 個月內的選舉合為一格（例如 2022 年 11/26 與嘉義市 12/18）。分組結果記錄在 Git 的人工審核表 `packages/etl/mappings/election-groups.csv`：程式依 12 個月規則提出建議，審核後才固定。地圖上標示各地區的實際投票日期。 |

## 2. 首長與民意代表

種類：

- 正副總統
- 立法委員（分選區）
- 縣市首長，含直轄市（分地區）
- 地方民意代表，例如議員（分地區／選區）
- 原住民立委、原住民議員、不分區政黨票：**放在獨立的檢視**，不與一般選區混用。

### 得票檢視方式

#### 兩大黨差異

藍－黑－綠漸層，兩種公式可以切換：

1. DPP% − KMT%，分母依「計入」選項而定。
2. (DPP − KMT) ÷ (DPP + KMT)，與分母選項無關。

處理規則：

- 某黨在該選舉沒有候選人時，該黨票數以 0 計算，公式不變。
- 公式 2 在兩黨都沒有候選人時是 0 ÷ 0，顯示為無資料（灰色）。
- 「黨」指候選人登記時的推薦政黨（中選會資料）；不處理政黨支持的無黨籍候選人。

#### 當選候選人

可選擇是否依得票率調整顏色深淺。**待確認**：哪些層級提供此檢視，見下方的待確認問題。

#### 各候選人得票率

兩種配色可選：

- 單色：政黨色到黑色。
- 多色彩漸層：例如 viridis。

### 地圖層級

- 縣市、鄉鎮市、村里三種層級。村里層級在 Phase 2 實作。
- 能以選區或地區分類時，提供選項標示特定選區或地區。

## 3. 公投

### 得票檢視方式

#### 同意與不同意差異

紅－黑－綠漸層：

- 綠 ＝ 同意，紅 ＝ 不同意。
- 另提供色盲友善配色的切換。

#### 個別得票率

同意與不同意可分別檢視；可選單色或多色彩漸層。

#### 通過門檻

投票環上以標線顯示通過門檻：同意票 ≥ 投票權人數 × 25%，且同意票多於不同意票。

### 地圖層級

縣市、鄉鎮市、村里。

## 4. 相依事項

- 政黨色：需要一份附來源、經審核的色票表（`packages/etl/mappings/party-colors.csv`）。
- 村里層級：需要先完成 Phase 2，包括村里群組合併繪製與私用區字元對照。
- 2016 年以前：屬於 Phase 4，代碼系統不同；官方村里界歷史圖資只追溯到 2017 年。
